
## Features
1. DarkMode
2. Servidor local para acceso en distintos dispositivos de la red
2. Subir e indexar los libros de manera automatica e individual
3. Vectorizacion de todos los libros mediante indexador.py
4. Buscador por frecuencia de palabras (TF-IDF)
5. Base de datos local para guardar la vectorizacion y no volver a calcularlo
6. Paginacion para obtener hasta 100 ocurrencias dentro de un umbral, ordenadas por mayor puntaje
7. Un check en la seccion del buscador, determina si se debe mostrar un solo libro por ocurrencia o no.
8. Abrir el PDF en la página encontrada y Ver pagina completa
9. Fragmento centrado en la coincidencia y términos resaltados.
